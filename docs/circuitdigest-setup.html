CircuitDigest SMS Setup

Get an API key, link phone numbers, and connect the voting station in six steps.

Setup checklist

0 / 6

    Request builder

    Fill in your values. The page checks them against the API rules and writes the code for you. Nothing leaves this page.

    
      
    
    
    
  
    

  
    
    
    Free plan limits
    
    
    
      
    100SMS per month, resets monthly
    
      
    5phone numbers linked per account
    
      
    30characters per variable
    
      
    Indianumbers only, prefix 91
    
    
    
    
    Per voter the firmware can send up to 3 messages: registration, the voter's vote receipt, and the admin notice. Turn off the ones you do not need in the console under Settings, SMS.
    
  
    

  
    
    
    
      
    Templates this project uses
    
      
    
        
    IDUsed forText
    
        
    111Voter, registered or votedThe task {var1} has been successfully completed at {var2}.
    
        
    101Admin, each vote and testsYour {var1} is currently at {var2}.
    
        
    107Admin alertError {var1} has been detected in {var2}.
    
      
    
      
    CircuitDigest offers 15 templates (101 to 115). To change wording, edit smsOnVote, smsOnRegister and smsAlert in the sketch.
    
    
    

    
    
      
    If it fails
    
      
    
        
    CodeMeaningFix
    
        
    401API key missing or wrongCopy the key again into secrets.h and re-upload
    
        
    403Request limit reachedWait for the monthly reset, or save quota
    
        
    400Missing or rejected fieldCheck number, template ID and variable length
    
        
    -1, -5Connection or TLS failedCheck WiFi and the free-heap numbers in the console
    
      
    
      
    The console's SMS tab shows the code and last response for every message.
    
    
    
  
    

  
    Two things I could not verify from the public docs: the exact menu where numbers are linked, and which code an unlinked number returns. Look for it in your CircuitDigest account, and trust the code shown in the console.
